# VK Z — iOS плеер для VK Музыки 🎵

**Разработчик: [Werhes](https://github.com/Werhes)**

**VK Z** — это нативный iOS клиент для VK Музыки с современным дизайном в стиле VK.

## Особенности

- 🎵 **Прослушивание музыки** — доступ к вашей музыкальной библиотеке ВКонтакте
- 📋 **Плейлисты** — просмотр и управление плейлистами
- 🔍 **Поиск** — поиск треков по названию и исполнителю
- 📱 **Мини-плеер** — управление воспроизведением из любого экрана
- 🎨 **Тёмная тема** — нативный тёмный дизайн в стиле VK
- 🔄 **Фоновое воспроизведение** — музыка играет в фоне
- 📻 **AirPlay** — поддержка AirPlay и Bluetooth
- 🔀 **Перемешивание и повтор** — гибкое управление очередью

## Технологии

- **SwiftUI** — современный UI фреймворк Apple
- **AVFoundation** — аудио-движок
- **Alamofire** — сетевые запросы
- **Kingfisher** — кэширование изображений
- **VK API** — официальное API ВКонтакте

## Требования

- iOS 17.0+
- Xcode 15.0+
- Swift 5.9+

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Werhes/VK-Z.git
```

2. Откройте проект в Xcode:
```bash
cd VK-Z
open VK-Z.xcodeproj
```

3. Соберите и запустите проект (⌘R)

## Авторизация

При первом запуске приложение запросит авторизацию через VK OAuth. 
Войдите в свой аккаунт ВКонтакте для доступа к музыкальной библиотеке.
